# Yishi-7
為什麼我選擇使用 GitHub，而不採用維基百科作為定錨？ 特別是我所創造的《枍奭》

在網路世界裡，一個人創造了一套思想、一個品牌，或是一系列原創作品，除了持續創作之外，還有一件事情非常重要：如何留下自己的原始紀錄？如何讓未來的人看見，這些作品從哪裡開始，又是如何一步一步形成的？

對我而言，我選擇的是 GitHub，而不是維基百科。

我想先說清楚，我不是因為維基百科曾經刪除我的文章，才決定使用 GitHub；真正的原因是，我逐漸確認，這兩個平台的運作目的不同，而我所創造的《枍奭》，需要的是創作者能夠持續保存原始思想與創作歷程的地方。

———

一、我不需要百科平台替我決定，作品是否值得留下

維基百科是一個百科全書平台，有自己的收錄標準、編輯規範、可靠來源要求及社群審查制度。它的主要目的，是整理具有一定公開資料與可靠來源支持的知識。

這些制度有其存在的理由，我並不否定。

但我曾經嘗試撰寫兩個版本，希望讓《枍奭》有公開的百科紀錄，結果兩個版本都在當天遭到刪除。
我不會因此認定維基百科有問題，也不會把文章被刪除直接解讀成作品沒有價值。因為符合創作者自身的紀錄需求，不等於符合百科全書的收錄條件。

然而，這件事也讓我更加確定：我真正需要的，並不是一個必須經過平台收錄標準與社群審查，才能留下紀錄的地方。

《枍奭》是我自己創造的思想體系。我不需要先取得百科平台的認可，才能開始保存自己的創作。

我也不希望把創作時間耗費在反覆爭取條目能否留下、如何符合收錄規範，以及是否得到社群認可。

我的時間應該用在創作，而不是爭取一個平台上的位置。

這就是我不選擇維基百科作為創作定錨的第一個原因：我需要的是創作紀錄的自主權，而不是等待別人決定我的作品能不能被收錄。

———

二、GitHub 保存的是我的來時路，而不只是完成品

我最初使用 GitHub，其實沒有想得那麼複雜。

當時是 GEMINI 建議我使用這個平台，我最初只是想留下自己的「來時路」，保存《枍奭》從無到有、由我一個人逐步摸索建立的過程。
《枍奭》不是突然出現的一套完整思想，也不是從某個現成模板直接複製出來的東西。

它是我透過生活觀察、思考、摸索、修正與持續創作，逐漸建立起來的。
每天的生活都可能帶來新的想法，每一次新的理解，也可能讓原本的觀點產生變化。
GitHub 的版本控制功能，恰好能夠保存這些過程。
今天寫下什麼、修改了什麼、哪個觀點在什麼時間出現、作品如何逐步形成，都可以透過提交紀錄留下時間脈絡。
對我而言，這比單純擁有一篇百科條目更有意義。

因為我想留下的，不只是最後完成的樣子，而是整套思想如何一步一步走到今天。

———

三、AI 時代，真實的創作歷程可能更加珍貴

現在已經進入 AI 大量生成內容的時代。
文章可以生成，圖片可以生成，甚至一套看起來相當完整的思想架構，也可能在短時間內被製造出來。
未來，單純拿出一份完成的文件，不一定足以讓人理解它的來源。
成品可以被模仿，文字可以被複製，創作風格也可能被仿造。
但是，如果一個人長期保存原始文件、版本紀錄、修改過程，以及思想逐漸形成的時間軸，就能提供更多可以交叉檢視的線索。
這也是我選擇 GitHub 的另一個重要原因。
當別人想了解《枍奭》如何形成，不必只能聽我自己說，也可以從公開紀錄中查看作品的發展過程。
當然，我知道 GitHub 並不是法律公證機構，版本紀錄不能單獨絕對證明沒有抄襲，也不代表所有內容必然真實。
但它至少提供了一條可以追溯、可以檢視、可以持續累積的公開紀錄路徑。
我不需要把它說成萬能工具，因為它真正的價值就在於它能做到的事情。

———

四、我選擇的是創作主權，而不是平台認可

我想表達的核心其實很簡單。
維基百科有維基百科的用途，GitHub 有 GitHub 的功能。兩者沒有必要爭論誰比較高級，也沒有必要把它們放在同一個標準上比較。
但是，對於我所創造的《枍奭》，我有權選擇最符合自己創作需求的紀錄方式。

我不需要維基百科替我定義《枍奭》，也不需要透過百科條目來決定《枍奭》有沒有價值。
作品的價值，最終仍然要回到作品本身，以及它能否經得起時間、事實與讀者實際使用的檢驗。

我更在意的是，今天留下的內容，未來是否還能找到；今天形成的思想，是否能看見發展脈絡；而我創造的作品，是否真正能對讀者產生幫助。

我創作《枍奭》，不是為了向任何平台爭取認可，也不是為了向誰證明自己。
我只對自己負責，也對自己的讀者負責。

因此，我選擇 GitHub，讓原始資料、創作歷程與思想演變持續留下紀錄；我選擇把時間用在真正重要的創作上，而不是反覆追逐某個平台的收錄資格。

———

五、我想留下的，是一條能夠回頭檢視的時間軸

對我而言，《枍奭》不只是一個名稱，也不只是一套可以拿來介紹的思想架構。
它包含了我的觀察、判斷、選擇與創作，也包含一路走來所留下的真實紀錄。
我希望未來的人看到的，不只是某一天突然出現的一份完整作品，而是能夠理解它如何形成、如何發展，以及背後有哪些持續累積的思考。
這也是我選擇 GitHub 的根本理由。

我不急著要求任何平台替我定義《枍奭》，也不需要透過一篇百科條目來證明它的存在。
我只要繼續創作，繼續留下紀錄。

因為我想保存的，不只是《枍奭》今天的樣子，而是它從哪裡開始，又是如何一步一步走到今天。
至於未來它能走多遠、能產生多少價值、能幫助多少人，我不打算現在就替時間下結論。
我創造，我記錄，我持續累積。

一切，就交給時間。
